### T2 路径调整说明

**原方案**：`txt → SequenceFile → HDFS → hbase Import → HBase 6 张表 → Hive 外部表关联 HBase`

**执行现象**：`hbase Import` 作业多次提交失败，依次报：

```
Resource ... changed on src filesystem
job.split does not exist
Input path does not exist: hdfs://master:9000/opt/module/hbase/lib/hbase-protocol-1.2.1.jar
```

**原因**：HBase 1.2.1 自带 Hadoop 客户端版本为 2.5.1，集群 Hadoop 版本为 2.7.3，两者在作业提交与文件本地化环节不兼容。

**调整后**：`txt → HDFS → Hive 外部表（直接读取文本文件）`

| 影响项 | 变化 |
|---|---|
| Hive 数据来源 | HBase → HDFS 文本文件 |
| 查询结果 | 一致，`count(1)` 经 MapReduce 实测为 1000000 |
| HBase 承担角色 | 由业务数据存储调整为 Kylin 元数据与 Cube 实体存储 |
| 对 T5 / T6 / T7 / T8 | 无影响，表名与字段名未变 |

**说明口径**：HBase 在本方案中承担 Kylin 元数据与 Cube 实体的存储职责；业务明细数据经 HDFS 由 Hive 外部表管理，以规避跨版本客户端兼容问题。

### 第 5 步：写视图（照这个骨架改）

`screen/views.py`：

```python
import pymysql
from django.shortcuts import render

DB = dict(host='127.0.0.1', port=3306, user='root',
          password='你的密码', database='yiyao', charset='utf8mb4')


def query(sql):
    conn = pymysql.connect(**DB)
    try:
        with conn.cursor(pymysql.cursors.DictCursor) as cur:
            cur.execute(sql)
            return cur.fetchall()
    finally:
        conn.close()


def index(request):
    # 图 2：用药 TOP10
    top10 = query("""
        SELECT p.m_drug AS name, SUM(p.amount) AS value
        FROM prescription_diseases p
        GROUP BY p.m_drug
        ORDER BY value DESC
        LIMIT 10
    """)

    # 图 4：病症出现次数 TOP10
    disease = query("""
        SELECT m_diagnostic AS name, COUNT(1) AS value
        FROM prescription_diseases
        GROUP BY m_diagnostic
        ORDER BY value DESC
        LIMIT 10
    """)

    return render(request, 'screen/index.html', {
        'top10': top10,
        'disease': disease,
    })
```

**注意**：数据库连接参数写成上面那种 `DB` 字典，方便组长部署时只改这一处。

1. 医药行业现在有什么问题（处方数据分散、用药趋势看不清、药品和适应症的对应关系不透明）


### 12 条 SQL（原样抄进文档）

**1. 城市等级竞争 `/home/citylevel`**

```sql
SELECT a.city_level_name,
       COUNT(1)      AS record_cnt,
       SUM(p.amount) AS total_amount
FROM prescription_diseases p
JOIN hosp_area a ON p.hosp_id = a.hosp_id
GROUP BY a.city_level_name
ORDER BY total_amount DESC;
```

**2. 年龄患病比例 `/home/age`**

```sql
SELECT age,
       COUNT(1) AS record_cnt
FROM prescription_diseases
GROUP BY age
ORDER BY age;
```

> 比例在程序里算：某年龄记录数 ÷ 总记录数。

**3. 销售金额 Top10 `/home/top10`**

```sql
SELECT p.m_drug                     AS drug_code,
       d.drug_generic_name          AS drug_name,
       SUM(p.amount)                AS total_amount
FROM prescription_diseases p
LEFT JOIN drug d ON p.m_drug = d.drug
GROUP BY p.m_drug, d.drug_generic_name
ORDER BY total_amount DESC
LIMIT 10;
```

**4. 各省份销量 `/home/province`**

```sql
SELECT a.province_name,
       COUNT(1)      AS record_cnt,
       SUM(p.amount) AS total_amount
FROM prescription_diseases p
JOIN hosp_area a ON p.hosp_id = a.hosp_id
GROUP BY a.province_name
ORDER BY record_cnt DESC;
```

**5. 联合用药 `/disease/union`**

```sql
SELECT CONCAT(IFNULL(m_diagnostic, ''), '+', IFNULL(m_diagnostic2, '')) AS combo,
       COUNT(1) AS record_cnt
FROM prescription_diseases
WHERE m_diagnostic IS NOT NULL
  AND m_diagnostic2 IS NOT NULL
GROUP BY combo
ORDER BY record_cnt DESC
LIMIT 10;
```

**6. 药品组合 `/disease/drug`**

```sql
SELECT drug_cnt_per_prescription,
       COUNT(1) AS prescription_cnt
FROM (
    SELECT m_prescription_id,
           COUNT(DISTINCT m_drug) AS drug_cnt_per_prescription
    FROM prescription_diseases
    GROUP BY m_prescription_id
) t
GROUP BY drug_cnt_per_prescription
ORDER BY drug_cnt_per_prescription;
```

**7. 疾病年龄分布 `/disease/age`**

```sql
SELECT m_diagnostic,
       CASE
           WHEN age < 7  THEN '0-6 婴幼儿'
           WHEN age < 18 THEN '7-17 少年'
           WHEN age < 41 THEN '18-40 青年'
           WHEN age < 66 THEN '41-65 中年'
           ELSE '66+ 老年'
       END AS age_group,
       COUNT(1) AS record_cnt
FROM prescription_diseases
GROUP BY m_diagnostic, age_group
ORDER BY record_cnt DESC
LIMIT 50;
```

**8. 科室分布 `/disease/section`**

```sql
SELECT m_section,
       COUNT(1)    AS record_cnt,
       SUM(amount) AS total_amount
FROM prescription_diseases
GROUP BY m_section
ORDER BY total_amount DESC
LIMIT 10;
```

**9. 药品覆盖城市 `/drug/cities`**

```sql
SELECT p.m_drug,
       COUNT(DISTINCT a.city) AS city_cnt
FROM prescription_diseases p
JOIN hosp_area a ON p.hosp_id = a.hosp_id
GROUP BY p.m_drug
ORDER BY city_cnt DESC
LIMIT 10;
```

**10. 药品覆盖医院 `/drug/hospital`**

```sql
SELECT m_drug,
       COUNT(DISTINCT hosp_id) AS hosp_cnt
FROM prescription_diseases
GROUP BY m_drug
ORDER BY hosp_cnt DESC
LIMIT 10;
```

**11. 药品对应适应症 `/drug/diseases`**

```sql
SELECT p.m_drug,
       p.m_diagnostic,
       d.disease_type_name13 AS disease_name,
       COUNT(1)              AS record_cnt
FROM prescription_diseases p
LEFT JOIN disease d ON p.m_diagnostic = d.disease_type13
GROUP BY p.m_drug, p.m_diagnostic, d.disease_type_name13
ORDER BY record_cnt DESC
LIMIT 20;
```

**12. 药品科室分布 `/drug/section`**

```sql
SELECT m_drug,
       m_section,
       COUNT(1) AS record_cnt
FROM prescription_diseases
GROUP BY m_drug, m_section
ORDER BY record_cnt DESC
LIMIT 20;
```
