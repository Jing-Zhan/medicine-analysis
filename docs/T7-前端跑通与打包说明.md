## 二、怎么跑起来（关键：Node 必须是 14.16.1）

工程是 **Vue 2 + webpack 3**，Node 16 及以上会编译失败。先确认版本：

```bash
node -v      # 必须是 v14.16.1
npm -v       # 6.14.12
```

版本不对就装 nvm 切换：`nvm install 14.16.1` → `nvm use 14.16.1`。

```bash
cd frontend/bigdataInCase-Medicine
npm install          # 依赖已装好时可以跳过
npm run dev          # 端口 8083
npm run build        # 产物在 dist/
```

**日常只需要两条命令：**

- 开发：`npm run dev` → 浏览器打开 <http://localhost:8083>
- 打包：`npm run build` → `dist/` 丢到 Tomcat `webapps/dist`

> Windows 用户如果 `npm run dev` 一启动就报 `EPERM ... mkdir '...\AppData\Roaming\npm'`，不是工程问题，是用户级 `~/.npmrc` 里的 `prefix` 指向了建不出来的目录。处理办法见 [第八节](#八常见问题)。

## 四、假数据是怎么接进去的（**重点，联调时别改错**）

### 为什么用适配层，而不是改 12 个组件

12 个图表组件的取数代码长得一样：

```js
Vue.ajax.send({ url: "/home/citylevel", data: {}, success: function (data) {
    if (!!data && data.code == '200') { /* 塞进图表 */ }
}})
```

如果逐个组件改，等于 12 处改动、12 个回归点。所以只在**入口套一层**：

```
组件里的 Vue.ajax.send  →  src/api/index.js 的适配层  →┬─ useMock=true  → src/mock 假数据
                                                       └─ useMock=false → 后端 baseUrl，失败/超时回退假数据
```

**组件里的取数代码一行没动**，这也是为什么切真实接口只需要改 `config.js` 里一个 `useMock`。

### 假数据的结构和组件取值方式是对齐的

全部返回 `{ code: '200', data: ... }`，`data` 的形态严格按组件 `success` 回调的取法来：

| 接口 | data 形态 |
| --- | --- |
| `/home/overview` | `[{ label, value, unit }]` |
| `/home/citylevel` | `{ YearData: [年份], CityData: [{ Level, BarData, LineData }] }` |
| `/home/age` | `{ AgeRange: [年龄段], AgeData: [[男], [女]] }` |
| `/home/top10` | `[{ Name, Amount, Counter }]` |
| `/home/province` | `[{ Name, Amount, Counter }]` |
| `/disease/union` | `[{ DiseaseName, DrugName, DrugCount }]`（树图） |
| `/disease/drug` | `{ Nodes: [{ name, value }], Links: [{ source, target, weight }] }`（和弦图） |
| `/disease/age` | `[{ Sex: '10'/'20', Age, Counter }]`（散点图，10=男 20=女） |
| `/disease/section` | `[{ SectionName, Counter }]`（饼图） |
| `/drug/cities` | `[{ Name, Counter }]` |
| `/drug/hospital` | `[{ Drug, Grade: '一级'~'四级', Counter }]`（堆叠柱状图） |
| `/drug/diseases` | `[{ Drug, Disease, Counter }]`（旭日图） |
| `/drug/section` | `[{ Drug, Section, Counter }]`（矩形树图） |

后端按这个结构返回就能直接上图，不用改前端。

### 两个细节

- **搜索框**：页面上的关键字会以 `?keyword=` 拼在 url 后面发给后端；假数据里也做了同样的过滤，匹配不到时返回全量，防止演示时一片空白。
- **兜底**：`useMock=false` 时如果后端挂了或超时 8 秒，会自动回退假数据，图表照样有图，不会白屏。

## 六、切真实接口，只需要两步（给 A / 组长）

打开 `frontend/bigdataInCase-Medicine/src/config.js`：

```js
export default {
    baseUrl: 'http://192.168.207.179:83',  // ① 后端地址，部署时只改这里
    useMock: true,                          // ② 接口通了改成 false
    mockDelay: 100
};
```

改完刷新页面即可，**组件代码不用动**。

⚠️ **一个需要注意的点**：首页概览用的 `/home/overview` 是前端新加的接口，T6 的 12 个接口表里没有它。如果后端不实现，切到 `useMock: false` 后这个请求会失败，卡片会走兜底逻辑**继续显示假数据**——演示能过，但不是真数据。要么 A 补一个 `/home/overview`（返回上面第四节的数组结构），要么告诉我改成从已有接口拼，两种都行。

## 七、打包与部署

```bash
npm run build        # 产物在 dist/
```

- `dist/index.html` 里资源是相对路径（`publicPath: './'`），整个 `dist` 丢到 Tomcat `webapps/dist`，访问 `http://<ip>:8080/dist` 即可
- 内存不够时先设 `NODE_OPTIONS=--max-old-space-size=4096`
- `dist/` 里目前 **5.8 MB 是 `static/` 下模板遗留的 echarts 副本**（`echarts.js` / `echarts.min.js` / `echarts-all.js`），运行时用不到，是 `CopyWebpackPlugin` 原样复制过去的。清掉后 dist 约 1.6 MB，要不要清等组长定

## 八、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 编译报一堆语法错 / `Unexpected token` | Node 版本太高（16+） | 切回 14.16.1 |
| `EPERM: operation not permitted, mkdir '...\AppData\Roaming\npm'` | 用户级 `~/.npmrc` 的 `prefix` 指向一个建不出来的目录 | `npm config set prefix <可写目录>`；或把 `prefix`/`cache` 改到工程旁边可写的位置 |
| 每次 npm 都弹 `npm update check failed` 黄框 | npm 6 更新检查写 `~/.config` 失败，**不影响构建** | `~/.npmrc` 加一行 `update-notifier=false` |
| `JavaScript heap out of memory` | 内存不够 | `NODE_OPTIONS=--max-old-space-size=4096` |
| `Module not found` | 依赖没装全 | 删 `node_modules` 重新 `npm install` |
| 图表只有 loading / 空白 | 接口没通且 `useMock=false` | 确认 `config.js` 的 `useMock`、`baseUrl` |
| 打开的页面没变化 | 没在 `feature/C-frontend` 分支 | GitHub 默认显示 `main`，记得切分支 |
