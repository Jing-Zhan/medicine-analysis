数据约 600MB，**不入 Git 仓库**（超过 GitHub 单文件上限），按下表从下发材料中取。

## 一、MySQL 数据

来源：`目标适应症及用药数据分析系统（分组）\项目数据\mysql_data\mysql_data\`

| 文件 | 大小 | 目标表 | 说明 |
| --- | --- | --- | --- |
| `sql.sql` | 4KB | — | 建库与建表语句，先执行 |
| `loadData.sh` | 1KB | — | 批量导入脚本，内含 6 条 `load data infile` |
| `t_view_areas.txt` | 153KB | `t_view_areas` | 区域维表 |
| `t_view_disease.txt` | 5.1MB | `t_view_disease` | 疾病维表 |
| `t_view_drug.txt` | 52MB | `t_view_drug` | 药品维表 |
| `t_view_hosp.txt` | 125KB | `t_view_hosp` | 医院维表 |
| `t_view_section.txt` | 12KB | `t_view_section` | 科室维表 |
| `yiyao.txt` | 181MB | `prescription_diseases` | 处方事实表 |

### 导入步骤

```bash
# 1. 建库建表
mysql -uroot -p123456 < sql.sql

# 2. 数据文件放到脚本约定路径
mkdir -p /home/bi_data/mysql_data
# 将上述 6 个 txt 上传到该目录

# 3. 执行导入
bash loadData.sh

# 4. 核对行数
mysql -uroot -p123456 yiyao -e "select 'prescription_diseases',count(*) from prescription_diseases union all select 't_view_drug',count(*) from t_view_drug;"
```

注意：`loadData.sh` 中的路径写死为 `/home/bi_data/mysql_data/`，若改路径需同步修改脚本。

## 二、HBase 数据

来源：`目标适应症及用药数据分析系统（分组）\项目数据\hbase_data\hbase_data\`

| 目录 | 大小 | 目标表 |
| --- | --- | --- |
| `AreaInfo_f` | 796KB | `AreaInfo_f` |
| `DiseaseInfo_f` | 16MB | `DiseaseInfo_f` |
| `DrugInfo_f` | 103MB | `DrugInfo_f` |
| `HospInfo_f` | 547KB | `HospInfo_f` |
| `PrescriptionDisease_f` | 356MB | `PrescriptionDisease_f` |
| `SectionInfo_f` | 63KB | `SectionInfo_f` |

每个目录内是 `part-m-00000` 形式的 **SequenceFile**（文件头 `SEQ`），需先上传 HDFS，再用 HBase 自带工具导入。

### 导入步骤

```bash
# 1. 上传到 HDFS
hdfs dfs -mkdir -p /bi_data/hbase
hdfs dfs -put ./AreaInfo_f /bi_data/hbase/

# 2. 建表（表名与目录名一致）
#    create 'AreaInfo_f', 'info'

# 3. 导入
hbase org.apache.hadoop.hbase.mapreduce.Import AreaInfo_f /bi_data/hbase/AreaInfo_f

# 4. 核对
echo "count 'AreaInfo_f'" | hbase shell
```

导入前确认：

```bash
df -h /home          # 磁盘空间
hdfs dfs -df -h      # HDFS 空间
```
