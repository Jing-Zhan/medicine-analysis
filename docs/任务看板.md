## 路径调整记录

### T2（HBase 导入）→ Hive 直接读 HDFS

| 项 | 内容 |
|---|---|
| 原方案 | txt → SequenceFile → HDFS → `hbase Import` → HBase 6 张表 → Hive 外部表关联 HBase |
| 执行现象 | `hbase Import` 作业提交失败，依次报 `Resource ... changed on src filesystem`、`job.split does not exist`、`Input path does not exist` |
| 原因 | HBase 1.2.1 自带 Hadoop 客户端为 2.5.1，集群 Hadoop 为 2.7.3，作业提交与文件本地化环节不兼容 |
| 调整后 | txt → HDFS → Hive 外部表（直接读取文本文件） |
| 结果校验 | `count(1)` 经 MapReduce 实测 = 1000000 |
| 影响 | HBase 承担 Kylin 元数据与 Cube 实体存储；表名与字段名未变，对 T5—T8 无影响 |
